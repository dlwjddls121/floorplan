평면도 앱 기기 시험 (0단계)

갤럭시 탭의 크롬에서 위에서부터 하나씩 해 보세요. 결과는 자동으로 기억됩니다. 다 끝나면 아래 [결과 복사]를 눌러 카톡이나 메일에 붙여넣어 보내 주세요.

◀ 평면도 앱(세대 목록)으로 돌아가기

아래 글을 길게 눌러 전체 선택 → 복사해 주세요.

    1. 펜 감지

    S펜이 화면에 닿기 전에 크롬이 알아채는지 봅니다. 아래 흰 칸에서 차례로 해 보세요.

    1. S펜을 화면 가까이 대 보세요 — 화면에 닿지 않게 1cm쯤 띄우고 움직입니다. (‘떠 있음’ 숫자가 올라가는지 보세요) 그다음 2초쯤 움직이지 말고 떠 있는 채로 가만히 들고 있어 보세요.
    2. S펜으로 그려 보세요 — 몇 번 그었다 뗐다 해 주세요.
    3. S펜을 든 채로 손바닥을 화면에 대 보세요 — 글씨 쓸 때처럼 손을 흰 칸에 올립니다.
    4. 펜을 멀리 치우고, 두 손가락을 동시에 흰 칸에 대 보세요.
    5. S펜 옆 버튼을 누른 채 흰 칸을 문질러 보세요 — 두 가지로 해 봅니다. ① 옆 버튼을 먼저 누른 채 펜을 화면에 대고 긋기 ② 펜을 화면에 대자마자(움직이기 전에) 옆 버튼을 누르고 긋기. 주황색 선이 나오면 앱에서 지우개로 쓸 수 있습니다. (메뉴가 뜨면 닫고 한 번 더 해 주세요)
    6. 펜을 화면에서 멀리(10cm 이상) 치운 뒤 손가락 하나로 칸을 눌러 보세요 — 1초쯤 기다렸다가 누릅니다. 파란 점이 찍히면 앱에서도 손가락으로 알아봅니다.
    검정 = S펜, 주황 = 옆 버튼을 누른 S펜(지우개), 파랑 = 손가락, 빨강 = 앱에서 손바닥으로 보고 무시할 손 터치(펜이 가까이 있을 때, 손바닥이 닿아 있는 동안)

    펜 신호 순서 (최근)

    아직 없음

      2. 드라이브로 보내기

      도면 파일을 구글 드라이브로 보낼 수 있는지 봅니다. 버튼을 누르면 공유 창이 뜹니다. “드라이브”를 고르고 [저장]을 눌러 주세요.

      드라이브에 파일이 생겼나요? (드라이브 앱이나 drive.google.com에서 확인)

        3. 파일 불러오기

        2번에서 드라이브에 저장한 파일을 다시 불러올 수 있는지 봅니다. 아래 버튼 → 파일 선택 창 왼쪽 메뉴(≡)에서 “드라이브” → 시험 파일(.txt)을 고르세요. 카메라·녹음만 나오는 창이 뜨거나, 파일이 회색으로 막혀서 고를 수 없으면 알려 주세요.

        PC에서는 파일을 이 칸에 끌어다 놓아도 됩니다.

          4. 저장공간

          도면이 기기 안에 안전하게 저장되는지 봅니다. 버튼을 누르면 크롬에 “이 앱 저장공간 유지”를 요청하고, 시험 기록을 저장했다가 다시 읽어 봅니다.

          홈 화면에 설치하기 전에는 크롬이 “저장공간 유지”를 거절하는 것이 보통입니다(고장이 아닙니다). 5번에서 홈 화면에 설치한 뒤 이 버튼을 한 번 더 눌러 주세요.

            5. 설치 · 인터넷 없이 열기

            1. 인터넷이 되는 곳에서 이 페이지를 한 번 엽니다(지금 상태). 몇 초 기다려 아래 ‘오프라인용 저장’이 ✅인지 봅니다.
            2. 홈 화면에 추가: 아래 [홈 화면에 설치] 버튼이 보이면 누릅니다. 안 보이면 크롬 오른쪽 위 ⋮ 메뉴 → “홈 화면에 추가”(또는 “앱 설치”)를 누릅니다.
            3. 비행기 모드를 켭니다.
            4. 크롬에서 이 페이지를 다시 엽니다(새로고침 ⟳). 페이지가 뜨면 성공이고, 자동으로 기록됩니다.
            5. 홈 화면의 평면도 아이콘도 눌러 봅니다. 앱 첫 화면이 뜨면 성공입니다.
            6. 비행기 모드를 끄고, 이 페이지에서 [결과 복사]를 누릅니다.
            홈 화면 아이콘이 비행기 모드에서 열렸나요?

              6. 출력 (한글 PDF · 고해상도 PNG)

              A4 인쇄용 시험 PDF(300dpi)를 만듭니다. 안에 100mm 사각형과 1:60 축척 예(3,000mm 벽 = 50mm), 한글 글자가 들어 있습니다.

              1. [시험 PDF 만들기] → [PDF 보내기]로 드라이브에 저장하거나 [PDF 내려받기]를 누릅니다.
              2. 인쇄할 때 크기를 “실제 크기”(또는 배율 100%)로 고릅니다. “페이지에 맞춤”은 끄세요.
              3. 인쇄한 종이를 자로 재서 아래 칸에 적어 주세요.
              4. 기기에 저장되는지: [고해상도 PNG 만들기] → [PNG 내려받기]를 누른 뒤 갤러리(사진) 앱의 Download 앨범을 열어 보세요. [PDF 내려받기]를 누른 뒤에는 내 파일 앱 → 다운로드를 열어 보세요. 보이는지 아래에서 답해 주세요. (앱에서 [출력] → [갤러리에 저장]을 누르면 같은 곳에 저장됩니다. 홈 화면에 설치한 앱에서도 한 번 해 보세요.)

                7. 기기 정보

                개발에 참고할 기기 정보입니다. 따로 할 일은 없습니다. (탭을 가로로 둔 상태에서 보내 주세요)

                  8. 미서기문 그림 확인

                  지금 도면에는 미서기문 예가 없어서, 제가 제안하는 모양입니다(원호 없이 겹친 문짝). 마음에 드시는지 골라 주세요.

                    9. 업데이트

                    탭에 설치한 앱이 새 버전을 제대로 받는지 봅니다. 5번(설치)을 먼저 해 주세요. 개발자와 함께 하는 시험입니다.

                    1. 인터넷이 되는 곳에서 [지금 버전 기록]을 누릅니다.
                    2. 개발자에게 “새 버전 올려 주세요”라고 알리고, 올렸다는 답을 기다립니다.
                    3. 홈 화면의 평면도 앱을 엽니다. 이미 열려 있었다면 다른 앱으로 갔다가 다시 돌아옵니다. 1~2분 안에 화면 위에 “새 버전이 있습니다 [지금 적용]”이 뜨는지 봅니다.
                    4. [지금 적용]을 누릅니다. 앱이 다시 열리면, 그려 두었던 도면이 목록에 그대로 있는지 봅니다.
                    5. 이 페이지로 돌아와 [버전 다시 확인]을 누르고, 아래 질문에 답해 주세요.
                    “새 버전이 있습니다” 안내가 떴나요?
                    [지금 적용] 뒤에 도면이 그대로 있었나요?
